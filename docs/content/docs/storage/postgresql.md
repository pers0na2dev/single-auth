title: "PostgreSQL"

Configure PostgreSQL namespaces, ID representations, transactions, and additive schema setup.

The PostgreSQL adapter uses an already opened `*sql.DB` and does not import a driver. Your application owns the handle, pool configuration, TLS settings, and shutdown.

## Complete setup with pgx

```go
package authsetup

import (
    "context"
    "database/sql"
    "fmt"

    _ "github.com/jackc/pgx/v5/stdlib"

    singleauth "github.com/pers0na2dev/single-auth"
    "github.com/pers0na2dev/single-auth/storage"
    postgresstore "github.com/pers0na2dev/single-auth/storage/postgres"
)

func OpenPostgreSQL(
    ctx context.Context,
    dataSourceName string,
    secret string,
) (*singleauth.Auth, *sql.DB, error) {
    if len(secret) < 32 {
        return nil, nil, fmt.Errorf("authentication secret must contain at least 32 characters")
    }

    database, err := sql.Open("pgx", dataSourceName)
    if err != nil {
        return nil, nil, err
    }
    if err := database.PingContext(ctx); err != nil {
        database.Close()
        return nil, nil, err
    }

    schema := storage.CoreSchema()
    adapter, err := postgresstore.New(database, postgresstore.Options{
        Schema:         schema,
        DatabaseSchema: "public",
        IDType:         postgresstore.UUIDID,
    })
    if err != nil {
        database.Close()
        return nil, nil, err
    }

    auth, err := singleauth.New(singleauth.Options{
        BaseURL:  "https://example.com",
        Secret:   secret,
        Database: adapter,
    })
    if err != nil {
        database.Close()
        return nil, nil, err
    }

    if err := auth.RunMigrationsContext(ctx); err != nil {
        database.Close()
        return nil, nil, err
    }

    return auth, database, nil
}
```

The caller must eventually call `database.Close()`.

When plugins, custom fields, or database-backed rate limits are enabled, replace `storage.CoreSchema()` with the [fully merged schema](/docs/storage/schemas) and pass the same plugin factories to `singleauth.New`.

## Constructor

```go
adapter, err := postgresstore.New(database, postgresstore.Options{
    Schema:               schema,
    DatabaseSchema:       "auth",
    IDType:               postgresstore.TextID,
    Clock:                time.Now,
    DefaultFindManyLimit: 250,
})
```

`postgresstore.New` validates its options but does not connect or mutate the database. A nil `*sql.DB` is rejected.

## Options

### `Schema`

A zero schema selects `storage.CoreSchema()`. The adapter clones the supplied schema.

### `DatabaseSchema`

The PostgreSQL namespace for unqualified model names. The default is `public`.

The namespace must already exist; the adapter creates tables inside it but does not issue `CREATE SCHEMA`.

An individual model can override the default with a qualified physical name:

```go
schema.Models["user"] = storage.ModelSchema{
    ModelName: "identity.auth_user",
    Fields:    schema.Models["user"].Fields,
    Order:     schema.Models["user"].Order,
}
```

Physical model names may contain either `table` or `schema.table`, never more components. Both components are quoted independently.

### `IDType`

| Value | Physical representation | Generation |
| --- | --- | --- |
| `postgresstore.TextID` | `TEXT` | Adapter-generated random text by default |
| `postgresstore.UUIDID` | Native `UUID` | `gen_random_uuid()` when no custom generator is supplied |
| `postgresstore.SerialID` | `INTEGER GENERATED BY DEFAULT AS IDENTITY` | Database-generated |

The zero value selects `TextID`. Public IDs and ID references are always returned as strings.

For `UUIDID`, supplying `IDGenerator` moves generation to the application. Without it, PostgreSQL must provide `gen_random_uuid()`.

### `IDGenerator`

Called with the canonical model name when the selected ID mode uses application-generated IDs:

```go
IDGenerator: func(model string) (any, error) {
    return model + "-fixed-id", nil
},
```

### `Clock`

Controls schema `DefaultValue` and `OnUpdate` callbacks. The default is `time.Now`.

### `DefaultFindManyLimit`

The zero value selects 100. Negative limits are rejected. To request zero records for one call, pass `Limit: storage.Int(0)` to `FindMany`.

## Physical scalar mapping

| single-auth type | PostgreSQL representation |
| --- | --- |
| String and enum | `TEXT` |
| Date | `TIMESTAMPTZ` |
| JSON and both array types | `JSONB` |
| Number | `INTEGER` |
| Number with `BigInt` | `BIGINT` |
| Boolean | `BOOLEAN` |

The adapter binds JSON as canonical text so pgx and lib/pq behave consistently, while the database stores it as `JSONB`.

Every non-ID schema field also has an internal Boolean presence column named `__single_present__<canonical-field>`. It preserves the difference between an omitted field and an explicit null. The prefix is reserved.

PostgreSQL identifiers are limited to 63 bytes. The constructor rejects longer model, field, schema, and generated presence-column names instead of allowing PostgreSQL to truncate them silently.

## Migrations

Run the adapter directly:

```go
if err := adapter.EnsureSchema(ctx); err != nil {
    return err
}
```

Or through the initialized runtime:

```go
if err := auth.RunMigrationsContext(ctx); err != nil {
    return err
}
```

`EnsureSchema` introspects the configured namespace, creates missing tables, adds missing fields and presence columns, and repairs missing indexes and foreign keys. DDL runs in one transaction and rolls back on failure.

It is additive only. It does not drop, rename, change types, or backfill application data.

## Offline plan

```go
plan, err := postgresstore.PlanSchemaWithDatabaseSchema(
    schema,
    postgresstore.UUIDID,
    "auth",
)
if err != nil {
    return err
}

sqlText := plan.SQL()
```

Available planners:

- `PlanSchema` uses text IDs and `public`.
- `PlanSchemaWithIDType` selects text, UUID, or serial IDs in `public`.
- `PlanSchemaWithDatabaseSchema` selects both ID type and namespace.

`adapter.CreateSchema(ctx, schema, path)` returns deterministic SQL in `storage.SchemaCreation`; it does not write to `path`.

## Transactions and concurrency

Each transaction uses `database/sql.BeginTx`. A callback error or outer context cancellation before commit rolls back the transaction. A successful callback is committed before `Transaction` returns.

Atomic consume and increment operations are single-statement guarded mutations. Multi-query joins operate against the same adapter and respect context cancellation.
