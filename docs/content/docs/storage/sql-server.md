title: "SQL Server"

Configure the SQL Server adapter, ID modes, OPENJSON requirements, and transactional schema setup.

The SQL Server adapter works with an existing `*sql.DB`. It is driver-neutral and uses SQL Server's `@pN` parameters.

SQL Server 2016 or newer with database compatibility level 130 or newer is required for `OPENJSON` queries.

## Complete setup

```go
package authsetup

import (
    "context"
    "database/sql"
    "fmt"

    _ "github.com/microsoft/go-mssqldb"

    singleauth "github.com/pers0na2dev/single-auth"
    "github.com/pers0na2dev/single-auth/storage"
    mssqlstore "github.com/pers0na2dev/single-auth/storage/mssql"
)

func OpenSQLServer(
    ctx context.Context,
    dataSourceName string,
    secret string,
) (*singleauth.Auth, *sql.DB, error) {
    if len(secret) < 32 {
        return nil, nil, fmt.Errorf("authentication secret must contain at least 32 characters")
    }

    database, err := sql.Open("sqlserver", dataSourceName)
    if err != nil {
        return nil, nil, err
    }
    if err := database.PingContext(ctx); err != nil {
        database.Close()
        return nil, nil, err
    }

    schema := storage.CoreSchema()
    adapter, err := mssqlstore.New(database, mssqlstore.Options{
        Schema: schema,
        IDType: mssqlstore.TextID,
    })
    if err != nil {
        database.Close()
        return nil, nil, err
    }

    auth, err := singleauth.New(singleauth.Options{
        BaseURL:  "https://example.com",
        Secret:   secret,
        Database: adapter,
    })
    if err != nil {
        database.Close()
        return nil, nil, err
    }

    if err := auth.RunMigrationsContext(ctx); err != nil {
        database.Close()
        return nil, nil, err
    }

    return auth, database, nil
}
```

The caller must eventually call `database.Close()`.

Use the [fully merged schema](/docs/storage/schemas) instead of `storage.CoreSchema()` when plugins, additional fields, or database-backed rate limits are enabled.

## Constructor and options

```go
adapter, err := mssqlstore.New(database, mssqlstore.Options{
    Schema:               schema,
    IDType:               mssqlstore.UUIDID,
    Clock:                time.Now,
    DefaultFindManyLimit: 250,
})
```

Options:

- `Schema`: zero selects `storage.CoreSchema()`.
- `IDGenerator`: custom application-side ID generation.
- `IDType`: text, UUID text, or SQL Server identity.
- `Clock`: defaults to `time.Now`.
- `DefaultFindManyLimit`: zero selects 100; negative values are rejected.

The constructor validates options but does not connect or mutate the database. A nil handle is rejected.

## ID types

| Value | Physical representation | Generation |
| --- | --- | --- |
| `mssqlstore.TextID` | `VARCHAR(36)` | Random text generated by the adapter |
| `mssqlstore.UUIDID` | `VARCHAR(36)` | RFC 4122 UUID generated by the adapter |
| `mssqlstore.SerialID` | `INTEGER IDENTITY(1,1)` | Database-generated |

The zero value selects `TextID`. Public IDs and ID references are strings in every mode.

## Physical scalar mapping

| single-auth type | SQL Server representation |
| --- | --- |
| Indexed, unique, sortable string or enum | `VARCHAR(255)` |
| Other string | `VARCHAR(8000)` |
| Date | `DATETIME2(3)` |
| JSON and both array types | `VARCHAR(8000)` containing JSON |
| Number | `INTEGER` |
| Number with `BigInt` | `BIGINT` |
| Boolean | `SMALLINT` |

Dates are encoded as UTC ISO strings. If a driver returns a zone-less `DATETIME2`, the adapter interprets it as UTC.

Every non-ID field has a hidden `__single_present__<canonical-field>` column to retain missing-versus-null semantics. The prefix is reserved.

SQL Server `sysname` identifiers are limited to 128 UTF-16 code units. Invalid names are rejected and generated index or constraint names are shortened deterministically when necessary.

## Returning mutations and triggers

Create, single-row update, `ConsumeOne`, and `IncrementOne` use `OUTPUT` to return the affected row atomically.

SQL Server rejects `OUTPUT` without `OUTPUT INTO` on a target table that has an enabled trigger for the same DML action. Consequently, tables managed by this adapter must not have enabled insert, update, or delete triggers that conflict with these operations.

## References

SQL Server does not have a `RESTRICT` keyword. The adapter emits `NO ACTION`, which provides the same immediate rejection behavior for these non-deferrable constraints.

`Cascade`, `SetNull`, and `SetDefault` are emitted directly. Always choose `Reference.OnDelete` explicitly, and make fields using `SetNull` optional.

## Migrations

```go
if err := adapter.EnsureSchema(ctx); err != nil {
    return err
}
```

`EnsureSchema` introspects the current database and schema, creates missing tables, adds missing fields and presence columns, and repairs indexes and foreign keys. The DDL runs in one `database/sql` transaction and rolls back on failure.

The migration is additive. It does not drop, rename, change field types, or backfill existing rows.

## Offline plan

```go
plan, err := mssqlstore.PlanSchemaWithIDType(
    schema,
    mssqlstore.SerialID,
)
if err != nil {
    return err
}

sqlText := plan.SQL()
```

`PlanSchema` uses text IDs. `adapter.CreateSchema(ctx, schema, path)` returns the generated SQL and path metadata without writing a file.

## Transactions

`adapter.Transaction` uses `database/sql.BeginTx`. Callback failure or outer-context cancellation before commit rolls back; success commits before the call returns.
