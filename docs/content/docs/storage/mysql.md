---
title: "MySQL"
---

Configure MySQL IDs, UTC date handling, guarded mutations, and additive migrations.

The MySQL adapter uses an existing `*sql.DB` and is independent of a concrete driver. Your application owns connection configuration, pooling, and shutdown.

For stable dates, configure the driver to parse timestamps and use UTC. The adapter accepts text timestamp results as a fallback, but interprets zone-less text as UTC.

## Complete setup

```go
package authsetup

import (
    "context"
    "database/sql"
    "fmt"
    "time"

    gomysql "github.com/go-sql-driver/mysql"

    singleauth "github.com/pers0na2dev/single-auth"
    "github.com/pers0na2dev/single-auth/storage"
    mysqlstore "github.com/pers0na2dev/single-auth/storage/mysql"
)

func OpenMySQL(
    ctx context.Context,
    address string,
    databaseName string,
    username string,
    password string,
    secret string,
) (*singleauth.Auth, *sql.DB, error) {
    if len(secret) < 32 {
        return nil, nil, fmt.Errorf("authentication secret must contain at least 32 characters")
    }

    config := gomysql.Config{
        User:                 username,
        Passwd:               password,
        Net:                  "tcp",
        Addr:                 address,
        DBName:               databaseName,
        AllowNativePasswords: true,
        ParseTime:            true,
        Loc:                  time.UTC,
        InterpolateParams:    true,
    }

    database, err := sql.Open("mysql", config.FormatDSN())
    if err != nil {
        return nil, nil, err
    }
    if err := database.PingContext(ctx); err != nil {
        database.Close()
        return nil, nil, err
    }

    schema := storage.CoreSchema()
    adapter, err := mysqlstore.New(database, mysqlstore.Options{
        Schema: schema,
        IDType: mysqlstore.TextID,
    })
    if err != nil {
        database.Close()
        return nil, nil, err
    }

    auth, err := singleauth.New(singleauth.Options{
        BaseURL:  "https://example.com",
        Secret:   secret,
        Database: adapter,
    })
    if err != nil {
        database.Close()
        return nil, nil, err
    }

    if err := auth.RunMigrationsContext(ctx); err != nil {
        database.Close()
        return nil, nil, err
    }

    return auth, database, nil
}
```

The caller must eventually call `database.Close()`.

Use the [fully merged schema](/docs/storage/schemas) instead of `storage.CoreSchema()` when plugins, additional fields, or database-backed rate limits are enabled.

## Constructor and options

```go
adapter, err := mysqlstore.New(database, mysqlstore.Options{
    Schema:               schema,
    IDType:               mysqlstore.UUIDID,
    Clock:                time.Now,
    DefaultFindManyLimit: 250,
})
```

Options:

- `Schema`: zero selects `storage.CoreSchema()`.
- `IDGenerator`: custom application-side ID generation.
- `IDType`: physical primary and foreign-key representation.
- `Clock`: defaults to `time.Now`.
- `DefaultFindManyLimit`: zero selects 100; negative values are rejected.

Construction validates options but does not connect or modify the database. A nil handle is rejected.

## ID types

| Value | Physical representation | Generation |
| --- | --- | --- |
| `mysqlstore.TextID` | `VARCHAR(36)` | Random text generated by the adapter |
| `mysqlstore.UUIDID` | `VARCHAR(36)` | RFC 4122 UUID generated by the adapter |
| `mysqlstore.SerialID` | `INTEGER AUTO_INCREMENT` | Database-generated |

The zero value selects `TextID`. Public IDs and ID references are strings in every mode.

MySQL has no portable native UUID type or UUID default used by this adapter, so UUID mode remains client-generated unless a custom generator is supplied.

## Physical scalar mapping

| single-auth type | MySQL representation |
| --- | --- |
| Indexed, unique, sortable string or enum | `VARCHAR(255)` |
| Other string | `TEXT` |
| Date | `TIMESTAMP(3)` |
| JSON and both array types | `JSON` |
| Number | `INTEGER` |
| Number with `BigInt` | `BIGINT` |
| Boolean | `BOOLEAN` |

Every non-ID field also receives a hidden `__single_present__<canonical-field>` Boolean column. This preserves missing versus explicit null. The prefix is reserved.

MySQL identifiers are limited to 64 Unicode characters. Longer model, field, presence-column, index, and constraint names are rejected or deterministically shortened where appropriate.

## Returning mutations

MySQL has no portable `INSERT`, `UPDATE`, or `DELETE ... RETURNING` form. Operations that must return a row use a real transaction. Guarded single-row changes claim the target with `SELECT ... FOR UPDATE` before mutating it.

This affects connection use: keep enough pool capacity for normal traffic, and propagate request contexts so blocked operations can be cancelled.

## References

Generated tables use InnoDB and inline foreign keys.

- `Cascade`, `Restrict`, `SetNull`, and `NoAction` are supported.
- `SetNull` requires an optional field.
- MySQL does not support the adapter's `SetDefault` reference action and schema planning rejects it.
- Always set `Reference.OnDelete` explicitly.

## Migrations

```go
if err := adapter.EnsureSchema(ctx); err != nil {
    return err
}
```

`EnsureSchema` acquires one pinned `*sql.Conn` because `FOREIGN_KEY_CHECKS` is session-local. It:

- introspects the current database;
- creates missing tables;
- adds missing fields and presence columns;
- repairs missing indexes and foreign keys;
- disables and restores foreign-key checks on that same connection;
- re-inspects on every retry.

MySQL DDL performs implicit commits. A failed migration can leave an earlier additive prefix applied even though the Go transaction reports an error. Do not reuse a failed static plan. Call `EnsureSchema` again so it inspects the new state and builds only the remaining work.

If restoring `FOREIGN_KEY_CHECKS` fails, the adapter marks the underlying connection unusable rather than returning it to the pool with checks disabled.

## Offline plan

```go
plan, err := mysqlstore.PlanSchemaWithIDType(
    schema,
    mysqlstore.SerialID,
)
if err != nil {
    return err
}

sqlText := plan.SQL()
```

`PlanSchema` uses text IDs. `adapter.CreateSchema(ctx, schema, path)` returns SQL metadata and does not write a file.

## Transactions

`adapter.Transaction` uses `database/sql.BeginTx`. Callback failure and context cancellation before commit roll back data changes. Successful callbacks commit before returning.

The non-atomic MySQL DDL warning applies to schema changes, not ordinary DML transactions.
